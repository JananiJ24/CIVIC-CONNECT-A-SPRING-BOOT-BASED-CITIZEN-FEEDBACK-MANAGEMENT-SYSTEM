# 🚀 CivicConnect – Citizen Feedback Management System

CivicConnect is a **Spring Boot MVC-based web application** that enables seamless communication between citizens and municipal authorities.  
The platform allows citizens to report civic issues, track resolution status, and provide feedback, while administrators can manage and respond to complaints in real time.

---

## 📌 Project Overview

Traditional complaint handling systems are slow, unorganized, and lack transparency.  
**CivicConnect digitalizes the entire feedback process** with:

- Centralized issue reporting  
- Real-time tracking  
- Role-based access  
- Secure authentication  
- Transparent governance  

This project supports **Smart City & E-Governance initiatives**.

## 🎯 Features

### 👤 Citizen Module
- User registration & login  
- Submit civic complaints  
- Track complaint status  
- Provide feedback/reactions  
- View announcements  

### 🧑‍💼 Admin Module
- View all complaints  
- Update status (Pending → In Progress → Resolved)  
- Manage users  
- Monitor feedback  

### 🔐 Security
- Role-based authentication  
- BCrypt password encryption  
- Session management  

---

## 🧩 System Architecture

Project follows **MVC Architecture**

- Model – Entities & Database  
- View – Thymeleaf UI  
- Controller – Business logic  
- Repository – Data Access Layer
